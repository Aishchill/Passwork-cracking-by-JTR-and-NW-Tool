# 🔐 Password Cracking – Cybersecurity Practical Lab

## 📌 Project Overview

This repository documents my Week 3 cybersecurity practical exercises focused on password security, password recovery, and password-cracking techniques.

The project covers two separate practical exercises using **John the Ripper** and **NW Tools** to understand how password-protected files and weak passwords can be assessed in an authorized testing environment.

## 🎯 Objectives

- Understand password security and authentication mechanisms.
- Explore password-cracking techniques.
- Learn how dictionary-based attacks work.
- Understand the security risks associated with weak passwords.
- Gain practical exposure to cybersecurity tools.

## 🛠️ Tools Used

### 1. John the Ripper

John the Ripper is a password security auditing and recovery tool.

**Activities:**
- Explored password hash formats.
- Practiced dictionary-based password attacks.
- Studied password recovery techniques.
- Analyzed the importance of password complexity.

### 2. NW Tools

Used NW Tools for a separate practical exercise involving password-protected PDF files.

**Activities:**
- Worked with password-protected PDF documents.
- Explored PDF password recovery techniques.
- Understood file password protection mechanisms.
- Studied the security implications of weak passwords.
